# Contributing

```bash
npm test
npm run docs:check
npm run pack:check
```

Use primary license evidence, realistic failure cases and tests of observable behavior. Keep the runtime dependency-free. Replacement work must be independently derived from requirements, interfaces, standards and tests unless the rightsholder has granted sufficient rights. Preserve required license texts, notices and attribution.

Manual agent evaluation scenarios are in [evals.json](../skills/commercial-license-skill/evals/evals.json); they are not a claim that every model or host has passed. [Review record](REVIEW.md), [architecture](ARCHITECTURE.md), [publishing](PUBLISHING.ko.md), [security](../SECURITY.md) and [changelog](../CHANGELOG.md) provide project details.
